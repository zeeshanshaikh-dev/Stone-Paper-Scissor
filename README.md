# Stone Paper Scissors 🎮

A simple command-line Stone Paper Scissors game built using Python.

## 🎯 Features

- Play Stone Paper Scissors against the computer
- Computer randomly selects its choice
- User input is mapped to numerical values
- Determines the winner using game logic
- Displays both the user's and computer's choices

## 🛠️ Concepts Used

- Python
- `random` module
- Dictionaries
- User input
- Conditional statements
- Variables
- Basic game logic

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the Python file:

```bash
python stone_paper_scissors.py
